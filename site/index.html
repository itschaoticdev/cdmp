Play Crimson Desert with a friend.

An unofficial co-op mod for the PC version. One player hosts, sends a room code, and the other joins. No Steam friendship or port forwarding needed.

Download the launcherHow it works

Version 0.3.0 alpha. Windows, Steam version. Signed by Kodian Anderson. Free.

How to play

  1. Both players need Crimson Desert on Steam and the launcher.
  2. Open the launcher. It finds the game and installs the mod when you press Start.
  3. The host picks Host a game, copies the code (like 4K7Q-M2XP-9TBD-3RNW) and sends it to their friend.
  4. The friend picks Join a friend and pastes the code.
  5. Both press Start Crimson Desert. The host loads in first; the friend appears once both are in the world.

Only share your code with the person you're playing with. Anyone who has it can join your game. Press New code to make a fresh one.

What works

This is an early alpha. Expect bugs, and keep a backup of your save.

Working

  • Seeing each other move, climb, glide and fight
  • Gear changes
  • Shared enemies: the guest's hits hurt, stagger and kill the host's enemies
  • Loot from kills
  • Horses (partly) and time of day

Not yet

  • The guest doesn't get quest progress or experience
  • Bosses, riders and archers in towers
  • The guest can see duplicate enemies
  • More than two players
  • Game updates can break the mod until it's updated

Help

The launcher can't find the gamePress Change... and pick the Crimson Desert folder (the one with bin64).
"Another mod's winmm.dll"Another mod already uses the same loader. Remove it, or install this mod by hand.
We can't see each otherCheck you both have the same launcher version and the guest typed the code right. The host has to be in the world first.
The game updated and crashesRemove the mod in the launcher and wait for an update.
Removing the modPress Remove in the launcher. It only deletes the files it added.
PrivacyGames go through a relay, so players never see each other's IP. Everything is encrypted with a key from the room code, and the relay can't read it.
