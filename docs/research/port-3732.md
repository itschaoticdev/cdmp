# Port to CrimsonDesert.exe 1.0.0.3732 (offline, not yet run in game)

Build 1.0.0.3732, Steam build 26776744, PE timestamp `0x6AFDC0CF`. Ported on Kody's gaming PC
from 3460 (`tools/port/cd_port.py`), cross-checked from 2976. The rest was resolved by hand with
`tools/port/resolve_manual.py`.

**Nothing here has been confirmed with `cdmp_probe`.** Do not sign or publish before
`cdmp_report.txt` is clean and co-op has been seen working.

## Unchanged, verify in game

All struct offsets, payload sizes, stat ids and the camera block layout are carried over from 3460
unchanged. `cdmp_probe report` checks the pointer chains. Same open items as 3460:
kVtPhysicsObject (`[[[ctrl+0x140]+0x2C0]]`) and kMinimapIconDecide.
`enemy_tables_2976.h` still lacks DLC enemies.

## Tooling changes

- `cd_port.py`: `rip_xrefs` now reads disp32 through four aligned int32 views in chunks. The old
  code built several 2.5 GB int64 arrays and ran out of memory on 32 GB. Results are identical
  (checked against the old math).
- `scripts/build.ps1`: picks the Visual Studio 18 2026 generator when that's the installed VS.
- `launcher.tests`: `CDMP_UNSIGNED=1` skips the signature check for unsigned dev builds.

## First in-game report (Nexus tester, 2026-11-23)

cdmp 0.3.0 + cdmp_probe on 1.0.0.3732 (PE 0x6AFDC0CF):

- OK: WorldSystem, ClientActorManager, ControlledActor, StatusComponent,
  CharacterControl vtables; static player pos; ClientClock head; Steam relay;
  all hooks installed; sniffer resolved 1179 opcodes; FieldTime 0x6F37C78 found.
- WRONG: `[control+0x140]+0x2C0` points at an object with no vtable, so the
  player reader failed with "physics data unreadable" the whole session.
  Camera block sentinel read 0.0.
- Probe false alarms (fixed in 0.3.1): heads read DIFFERENT because the mod had
  already hooked them; opcode MISMATCH because the probe used 3460 Troc
  instance RVAs; the version label still said 3460. Frame clock did not move
  during the 1 s sample (game probably paused or unfocused).

0.3.1: the player reader and camera reader search for the moved objects at
runtime (common/layout_search.h). Physics = a transform (3 orthonormal axis rows
then a position) whose position + chunk origin equals kStaticPlayerPos, at most
two pointers down from control+0x140 or control. Camera = the block holding the
6360000.0 sentinel, accepted only with a unit forward vector the view matrix
agrees with. Both log the offsets they find ("Please report this line"): put
those into offsets.h once a tester sends them.
